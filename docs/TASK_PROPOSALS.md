# Task Proposals

Use this file only for proposed backlog changes that need a short record before becoming executable tasks.

## Rules

- A proposal is not a commitment.
- The developer must explain proposed changes directly to the user before coding.
- Accepted proposals should become tasks in `docs/TASKS.md`.
- Rejected or deferred proposals stay here only when useful for future context.

## Template

```text
## PROP-000 - Short title

Status: Proposed | Accepted | Deferred | Rejected

Motivation:
- Why this change is useful.

Scope:
- What is included.
- What is excluded.

Decision:
- What must happen for this to become a task.
```
